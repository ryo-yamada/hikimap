# hikimap
Python-based port scanner that is *not* better than nmap.

I just wanted to make this because, why not?

Compiled with PyInstaller

## Use guide
1. Open releases tab
2. Download latest Python-based executable
3. Run in terminal like so: `./hikimap [target]`

Linux only
